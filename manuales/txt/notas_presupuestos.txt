🔗 INTEGRACIÓN CON OTROS MÓDULOS
================================================================================

El módulo de Presupuestos es el CENTRO del ERP VAH. Se integra con:

1. Clientes - Para selección y creación de clientes
2. Materiales Aluminio - Para precios por color y largo
3. Materiales Herrajes - Para precios de herrajes
4. Materiales Herrería - Para kg/m de perfiles
5. Materiales Vidrio - Para precio por m²
6. Materiales Plásticos - Para precio unitario
7. Materiales Otros - Para precio unitario
8. Paquetes Aluminio - Expansión de paquetes
9. Paquetes Herrajes - Expansión recursiva de herrajes
10. Parámetros Sistema - Configuración de correo y números iniciales

================================================================================
✅ CORRECTOR ORTOGRÁFICO
================================================================================

El corrector ortográfico profesional incluye:
- Subrayado en ROJO de palabras mal escritas
- Sugerencias automáticas al hacer clic derecho
- Agregar palabras al diccionario personalizado
- Gestión del diccionario desde menú Ayuda
- Soporte para español (México) con diccionario es_MX
- Alto rendimiento incluso con textos largos
- CORREGIDO: Manejo correcto de mayúsculas
- CORREGIDO: Palabras en MAYÚSCULAS ya no se marcan todas como error

Para instalar el diccionario es_MX:
    1. Ejecutar reports/instalar_diccionario_espanol.py
    2. Instalación automática o manual

Para usar language_tool_python (más preciso):
    pip install language-tool-python
    (requiere Java instalado)
